    About Markdown Reader

    Markdown Reader is a free web app to read, live-preview and analyze Markdown. Type or paste Markdown — or load it from any URL or GitHub link — and instantly see the rendered output alongside a structured analysis: word count, reading time, a table of contents, links, images, code blocks, task progress and tables. It also exposes a small JSON analysis API so other programs and AI agents can fetch and analyze Markdown programmatically. It is a more feature-rich, themeable alternative to markdownlivepreview.com.

    Features

    • Live previewA resizable split-pane editor renders Markdown as you type.
    • Load from URLFetch Markdown from any public URL; GitHub blob links are auto-converted to raw.
    • Analysis APIA documented JSON API returns counts, headings, links, code blocks and task progress.
    • Light & darkTheme toggle that remembers your choice, with system-preference default.
    • Safe renderingHTML is sanitized server-side and client-side to prevent XSS.
    • Export & embedCopy HTML, download .md/.html, and embed in a webview with ?embed=1.

    Analysis API

    Markdown Reader is built around a small, stable HTTP API so you can automate Markdown analysis:

    • POST /api/analyze — send { "markdown": "…" }, get back sanitized html plus an analysis object (word count, reading time, headings, links, images, code blocks, tasks, tables).
    • GET /api/fetch?url=… — fetch Markdown from a URL (server-side, CORS-free) and get its raw text, sanitized HTML and analysis.
    • GET /api/health — a simple health check.

    Frequently asked questions

    What is Markdown Reader?

    Markdown Reader is a free web app that renders a live preview of Markdown and computes a structured analysis of it (word count, reading time, headings, links, images, code blocks, tasks and tables). It also exposes a JSON HTTP API so other programs and AI agents can fetch and analyze Markdown programmatically.

    Can it read Markdown from a URL?

    Yes. On GitHub Pages, paste a CORS-enabled public Markdown URL (or a GitHub blob link, which is automatically rewritten to its raw form) and it is fetched directly in the browser, then rendered and analyzed. The optional API server can fetch server-side when CORS blocks browser reads.

    Does Markdown Reader have an API?

    Yes. POST /api/analyze accepts { markdown } and returns sanitized HTML plus an analysis object. GET /api/fetch?url= fetches Markdown from a URL and returns its raw text, sanitized HTML and analysis. GET /api/health is a health check.

    How is it different from markdownlivepreview.com?

    Markdown Reader adds loading Markdown from a URL, a documented JSON analysis API, a table-of-contents and document-statistics panel, light/dark themes, export options, and an embeddable mode for webviews — with a different, more polished UI.

    Can I embed Markdown Reader in another app or webview?

    Yes. Add ?embed=1 to the URL to hide the surrounding chrome for a clean embed in an iframe or mobile webview. You can also pass ?url= to auto-load a document and ?theme=dark or ?theme=light to force a theme.
